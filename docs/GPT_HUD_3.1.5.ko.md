# GPT HUD 3.1.5 — UI 정돈과 정식 단일 배포

## 승인·기준·실행 계획

2026-10-25 사용자가 로컬 UI/UX 개선분의 정식3.1.5 반영·검증·배포와 베타 신규 개발 종료 및 정리 수순을 명시적으로 승인했다. 기준은 공개 정식3.1.4/code91 `fc5471e612f6e7d1b6a9cdbf50aaae1ae2bbf585`다. 새 정식3.1.5/code92는 기존 패키지 `dev.bennett.codexmeter`, 기존 인증서, 기존 업데이트 경로를 유지한다.

검토본의17개 UI 파일만 선별했다. 베타 패키지·매니페스트·파서·채널·내부 권한은 가져오지 않는다. 계획은 정식 소스/회귀→빌드/lint/서명→공개3.1.4 합성 설치 기준→정식 배포/익명 자산 검증→기존 설치의 앱 다운로드·Android 설치 및 보존 대조→베타 로컬 검토본 회수다.

## 구현

- 홈의 티어·이름·칭호·레벨과 두 잔여 한도를 유지하고 숫자/막대/상세 진입의 역할을 정리했다. 주간 한도 주기, 관측0/자료 없음과 로컬 관측 상세를 구분한다.
- 기록 읽기 실패를0일과 구분하고 마지막 정상 기록/재시도를 제공한다. 계정 변경 때 이전 계정 화면을 지운다. 좁은 화면/큰 글씨에서는 선택한 주를 표시하고 가용 폭에 따라 날짜48dp를 확보한다.
- 메달 기록 버튼은 실제 기록 화면으로 이동한다. 도감의 빈 상태는 활동 메달도 포함해 판단한다. 중복 칭호 표시와 획득 근거를 구분하고 보유품부터 보여준다.
- 세 탭에 동일한 설정 버튼을 제공한다. 한마디ON/OFF를 직접 노출하고4개 설정 그룹과 복구의 진행/완료/실패를 정리했다. 계정창은 큰 글씨에서 세로/가변 높이를 사용한다.
- 문구624ID·40팁과 자동 선택/끄기/숨김/명시적 복사, 성장/XP/업적/칭호/장착/이전 보관함의 저장소와 스키마를 유지한다. 새 런타임AI API/서버/권한/대화 분석/클립보드 감시는 추가하지 않는다.

## 베타 종료·정리

- 공개 베타는 종료 상태를 유지하며 새 베타 릴리스·태그를 만들지 않는다. 정식 소스의 베타 빌드/배포 워크플로를 제거한다.
- 잘못 만든9.9.15 검토 APK와 작업본은 정식 공개·검증 완료 뒤 로컬 복구 보관으로 회수한다. 사용자 미커밋 변경이 있는 이전 베타 원본은 복구 가능성을 확보하기 전 삭제하지 않는다.
- 과거 beta 이름의 클래스/DB/설정 키는 이미 정식 데이터와 연결돼 있으므로 호환 식별자로 유지한다. 이를 삭제하거나 이름을 바꿔 데이터를 초기화하지 않는다.
- 사용자 폰의 베타 앱/데이터를 자동 삭제하지 않는다. 두 패키지의 기록은 자동 병합되지 않는다. 필요한 성장/설정 백업과 정식의 복원 지원 범위·실제 보존 확인 후 사용자가 베타 앱 삭제를 선택한다. 로그인·사용량 전체 이력 자동 이전을 주장하지 않는다.
- 이전 공개 릴리스/자산·서명키·중요 복구 자료와 기존 미커밋 작업은 보존한다. Drive 자동 업로드는 실행하지 않는다.
